方法一：通过克隆（推荐给新手）
步骤1：克隆远程仓库到本地
bash
# 打开终端，进入要存放项目的目录
$ cd /d/dev

# 克隆仓库
$ git clone https://github.com/用户名/仓库名.git

# 或使用SSH
$ git clone git@github.com:用户名/仓库名.git
步骤2：进入克隆的目录
bash
$ cd 仓库名
步骤3：将要传送的文件复制到该目录
bash
# 例如，将文件从其他地方复制过来
$ cp "/d/其他位置/文件.txt" .
# 或直接将文件拖放到克隆的文件夹中
步骤4：添加文件到Git
bash
# 添加所有新文件
$ git add .

# 或添加特定文件
$ git add 文件名.txt
步骤5：提交更改
bash
$ git commit -m "添加新文件"
步骤6：推送到远程仓库
bash
$ git push origin main
# 如果分支是master，则使用：git push origin master
方法二：在现有项目目录中操作
如果您已经有一个包含文件的本地目录：

步骤1：初始化Git（如果还没初始化）
bash
# 进入项目目录
$ cd "/d/dev/我的项目"

# 初始化Git仓库
$ git init
步骤2：连接到远程仓库
bash
# 添加远程仓库地址
$ git remote add origin https://github.com/用户名/仓库名.git

# 验证远程仓库
$ git remote -v
步骤3：拉取远程仓库内容（如果远程有文件）
bash
# 如果是第一次同步，可能需要拉取远程内容
$ git pull origin main --allow-unrelated-histories
步骤4：添加本地文件
bash
# 添加所有文件
$ git add .

# 或添加特定文件
$ git add 文件夹/文件.txt
步骤5：提交更改
bash
$ git commit -m "添加我的项目文件"
步骤6：推送到远程
bash
$ git push -u origin main
# -u 参数设置上游分支，以后可以直接用 git push
